# Zero Defect Design Assistant

Веб-приложение на Next.js для оценки UX/UI макетов с помощью Gemini 2.5 Pro. Поддерживает загрузку дизайн-системы в Vercel Blob и ведение истории оценок.

## Возможности

- Загрузка дизайн-системы (md, txt, pdf, doc) и изображений макетов в Vercel Blob Storage.
- Проверка входных данных с использованием Gemini: соответствие JSON макету и ясность бизнес-задачи.
- Пошаговая оценка макета (обзор, качество дизайна, доступность, дизайн-система) с последующей генерацией отчёта.
- Сохранение результатов в Vercel Blob и просмотр истории оценок без авторизации — приложение работает в демонстрационном режиме.

## Подготовка окружения

1. Свяжите проект с Vercel и подтяните переменные окружения:
   ```bash
   vercel link
   vercel env pull
   ```
2. Убедитесь, что задана переменная:
   - `Zero_Defect_Gemini` — API-ключ Gemini 2.5 Pro.
3. Установите зависимости и запустите проект:
   ```bash
   npm install
   npm run dev
   ```

## Структура приложения

- `app/` — маршруты Next.js (App Router).
- `components/` — UI-компоненты.
- `lib/` — утилиты для Gemini и Vercel Blob.
- `app/api/` — API-роуты для загрузок и оценок.

## Примечания

- Промпты для этапов оценки вынесены в `lib/evaluation.ts` как placeholders `[[PROMPT_*]]` и должны быть заполнены.
- Для корректной работы Vercel Blob требуется активированная база данных Blob в проекте Vercel.
- Серверные роуты используют Node.js runtime (по умолчанию в Next.js) и требуют Node.js 18+ с поддержкой `fetch`.
- Файл `vercel.json` фиксирует команду сборки (`npm run build`), сохраняя остальную конфигурацию по умолчанию Vercel для Next.js.
